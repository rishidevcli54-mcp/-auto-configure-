# GitHub Keyboard Shortcuts Cheat Sheet

Quick reference guide for GitHub keyboard shortcuts. Press `?` on any GitHub page to see all available shortcuts for that page.

---

## 🌐 Site-Wide Shortcuts

| Shortcut | Description |
|----------|-------------|
| <kbd>S</kbd> or <kbd>/</kbd> | Focus the search bar |
| <kbd>G</kbd> <kbd>N</kbd> | Go to your notifications |
| <kbd>Option</kbd>+<kbd>↑</kbd> (Mac) / <kbd>Alt</kbd>+<kbd>↑</kbd> (Windows/Linux) | Move focus to element's hovercard |
| <kbd>Esc</kbd> | Close hovercard |

## ✏️ Source Code Editing

### Editor Shortcuts
| Shortcut | Action |
|----------|--------|
| <kbd>.</kbd> | Open in github.dev (same tab) |
| <kbd>></kbd> | Open in github.dev (new tab) |

### Text Formatting (Markdown)
| Shortcut | Format |
|----------|--------|
| <kbd>Command</kbd>+<kbd>B</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>B</kbd> (Windows/Linux) | **Bold** |
| <kbd>Command</kbd>+<kbd>I</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux) | *Italic* |
| <kbd>Command</kbd>+<kbd>E</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>E</kbd> (Windows/Linux) | `Code` (one-liner) |
| <kbd>Command</kbd>+<kbd>K</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>K</kbd> (Windows/Linux) | [Link](#) |
| <kbd>Command</kbd>+<kbd>Shift</kbd>+<kbd>7</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>7</kbd> (Windows/Linux) | Ordered list |
| <kbd>Command</kbd>+<kbd>Shift</kbd>+<kbd>8</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>8</kbd> (Windows/Linux) | Unordered list |
| <kbd>Command</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> (Mac) / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> (Windows/Linux) | > Quote |

|----------|--------|

## 💡 Pro Tips

- **Customize shortcuts**: You can disable character key shortcuts in your accessibility settings while keeping modifier key shortcuts
- **Use Command Palette**: Press the command palette for quick access to actions without memorizing shortcuts
- **Context matters**: Different shortcuts are available on different pages (press `?` to see them)
- **Search first**: Use <kbd>S</kbd> or <kbd>/</kbd> to quickly search across GitHub
